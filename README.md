# AI Agent Skills

A collection of reusable skills for AI coding agents.

## Install

Each skill name below opens its page on [skills.sh](https://skills.sh/joacod/skills). That page has a copy button for the install command.

```bash
npx skills add https://github.com/joacod/skills --skill <skill-name>
```
